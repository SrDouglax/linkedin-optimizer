# 🚀 LinkedIn Optimizer AI

A **minimalist, high-performance** AI assistant to audit your LinkedIn presence and strategic growth. Powered by **Gemini 3 Flash**.

> **Built with AI:** Created to provide a quick solution for a specific need.

## 🛠️ Minimal Setup

1. **Clone & Install**

   ```bash
   git clone https://github.com/SrDouglax/linkedin-optimizer
   npm install
   ```

2. **Run Dev**

   ```bash
   npm run dev
   ```

3. **Get Results**
   Open `http://localhost:5173`. You'll need a API Key from [Google AI Studio](https://aistudio.google.com/app/apikey).

## 💡 How to Audit

Due to LinkedIn's privacy layers, automatic scraping is often blocked. For a **WOW** analysis:

1. Open your LinkedIn Profile.
2. Press `CTRL + A` then `CTRL + C` on your profile page.
3. Paste the text into the app.

## 🧰 Tech Stack

- **Engine**: React + Vite + TypeScript
- **Intelligence**: Gemini 3 Flash Preview
- **Style**: Tailwind CSS v4 (Glassmorphism Tier)
- **Fluidity**: Framer Motion
